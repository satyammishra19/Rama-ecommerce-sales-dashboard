# Rama Ecommerce Sales Dashboard

## Project Overview
This Power BI dashboard provides an in-depth analysis of ecommerce sales performance. The dashboard helps track sales, profit, quantity sold, customer behavior, and category-wise performance through interactive visualizations.

## Tools Used
- Power BI
- Microsoft Excel

## Key KPIs
- Total Sales
- Total Profit
- Total Quantity Sold
- Profit by Month
- Sales by State
- Sales by Category
